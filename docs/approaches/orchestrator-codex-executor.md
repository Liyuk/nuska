# 多 Agent 编排与执行：通用方案草案

状态：概念草案 · 2026-11-10。本文描述一种可供研究的通用分工方式，不代表实际部署、运行结果或已验证的产品能力。

## 基本分工

- 用户确定目标、授权范围和验收标准。
- 编排角色拆解任务、协调执行并汇总结果。
- 执行角色在受限环境中完成具体工作，返回产物与验证证据。
- 确定性脚本可用于调度和检查；涉及外部操作时遵循实际环境的权限策略。

## 工作流程

1. 以自包含任务描述记录目标、输入、约束、预期产物和验收方式。
2. 在适当隔离的环境中执行，并记录进度、失败和外部操作的结果。
3. 对产物运行适合任务的检查；未通过时根据失败原因有限重试或交由负责人处理。
4. 汇总已完成内容、验证证据、未解决问题和需要用户决定的事项。

## 待验证问题

任务分解是否改善交付质量、检查能否覆盖真实目标、失败恢复是否避免重复副作用，以及额外协调成本是否值得，都需要在具体场景中通过实验评估。方案本身不能替代权限控制、独立验收或人工判断。
