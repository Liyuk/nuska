# Nuska

**Understand the intent. See it through.**

Nuska 是一个长期研究与实践项目，探索如何让 AI 理解人的意图，自主推进长任务，并交付可验证、符合目的的结果。

人可以从一个尚未完全成形的想法开始，通过对话逐渐表达目的。系统需要判断哪些内容可以自行推断、哪些关键问题需要询问，然后尽可能独立地规划、执行、处理失败、检查结果并完成交付。

## 研究问题

- 如何理解用户真正的目标，并在任务推进或目标改变时保持一致？
- 如何让长任务在有限监督下持续推进、发现停滞并从失败中恢复？
- 如何判断交付是否完整、可信，是否满足用户的目的？
- 如何让用户在需要时了解进展、提供判断和改变方向？
- 如何在体验、可靠性和使用成本之间做出合理取舍？

## 名称

Nuska 源自美索不达米亚神话。在一则古代文本中，Nuska 领会意图、与委托者商议，并代为执行。这个形象为项目的研究方向提供了灵感。[来源：牛津大学苏美尔文学电子文本语料库](https://etcsl.orinst.ox.ac.uk/edition2/etcslgloss.php?charenc=&lookup=c4051.104&sn=ON)。
